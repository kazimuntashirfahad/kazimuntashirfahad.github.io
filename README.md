# Kazi Fahad — Portfolio (GitHub Pages)

A plain HTML/CSS/JS website. It runs on free GitHub Pages without needing any server.

## Live korar niyom (step by step)
1. github.com-e free account khulun.
2. Upore dane **+** → **New repository** → nam din `apnar-username.github.io` → **Public** → **Create repository**.
3. Computer-e `portfolio-github.zip` **Extract** korun.
4. Repository page-e **uploading an existing file** link-e click korun.
5. Extract kora folder-er **bhitorer sob file ar folder** (index.html, assets, blog …) eksathe select kore browser-e drag korun. Upload shesh hole niche **Commit changes** chapun.
6. **Settings** → bam dike **Pages** → Source: **Deploy from a branch** → Branch: **main**, folder: **/ (root)** → **Save**.
7. 1–2 minute por `https://apnar-username.github.io` kholun. Site live!

## Info update korar niyom
- **Lekha bodlano:** GitHub-e file kholun (jemon `about.html`) → upore ✏️ (Edit) → lekha bodlan → **Commit changes**. 1 minute-er moddhe site update hobe.
- **Photo:** `assets/img` folder kholun → **Add file → Upload files** → nijer chhobi `portrait.jpg` name-e upload korun (purono-ta replace hobe).
- **CV:** `assets/files` folder-e `Kazi_Fahad_CV.pdf` name-e upload korun.
- **Notun blog post:** `blog` folder-er kono post copy kore notun name din, lekha bodlan, tarpor `blog.html`-e link add korun.

## Contact form (free, optional)
GitHub nije email pathate pare na. Ekhon form visitor-er email app khule dey.
Form theke sorasori email pete:
1. formspree.io-te free account khulun → **New form** → form ID copy korun (jemon `xyzabcd`).
2. GitHub-e `contact.html` edit korun → `YOUR_FORM_ID` likha jayga-ta apnar ID diye replace korun → Commit.

## Note
- Admin panel-wala PHP version GitHub-e chole na. Sei version shudhu PHP hosting-e (jemon Hostinger) kaj kore.
